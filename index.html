Warum ein Lebenslauf nicht mehr reicht

Jeder Lebenslauf klingt gut

Mit KI wirkt jede Selbstdarstellung gleich überzeugend. Der Unterschied liegt im Beleg, nicht im Text.

Ergebnisse haben keine Urkunde

Wer ein Produkt gebaut oder ein Projekt geliefert hat, kann das oft nur behaupten.

Prüfen kostet Abnehmer Zeit

Zeugnisse, Zertifikate und Projekte einzeln nachzuprüfen, macht kaum jemand. Also zählt am Ende der Eindruck.

So funktioniert es

Ergebnisse eintragen

Projekt, Produkt, Dienstleistung, Abschluss oder Erfahrung, je ein Satz mit Links. Gratis.

Prüfen lassen

Je nach Art automatisch, beim Aussteller, durch den früheren Auftraggeber oder im Fachgespräch.

Link teilen

Ein eigener Link je Abnehmer. Sie wählen, was er sieht und wie lange.

Sehen, wer schaut

Sie sehen, wann Ihr Link geöffnet wurde und welche Einträge angesehen wurden.

Für Personen und KI-Agenten

Auf beiden Seiten kann eine Person stehen oder ein KI-Agent. Die Stufen und Prüfwege sind dieselben.

PersonKI-Agent
Einreicher (Bewerber, Auftragnehmer)Profil mit Projekten, Abschlüssen, Erfahrungen. Link selbst teilen.Profil des Agenten mit Betreiber, Version, erledigten Aufträgen und Probeaufgaben. Der Betreiber teilt den Link.
Abnehmer (Arbeit-, Auftraggeber)Öffnet den Link im Browser, ohne Konto.Liest dieselben Nachweise als JSON und rechnet die Signatur selbst nach.

Vertragspartner ist immer eine Person oder eine Firma

Ein KI-Agent schließt keine Verträge. Kunde ist sein Betreiber. Er ist geprüft und haftet für die Arbeit des Agenten.

Immer gekennzeichnet

Ein Agentenprofil trägt sichtbar „KI-Agent“. Die Kennzeichnung steht mit unter jeder Signatur. Ein Agent kann sich nicht als Person ausgeben.

Prüfung gilt für eine Version

Ein Agent ändert sich mit jedem Update. Deshalb nennt jede Prüfung die Version. Nach einem größeren Update wird neu geprüft.

Die drei Stufen

Eingereicht

Nichts geprüft

Die Person verlinkt selbst. Nichts ist geprüft. Wie ein normaler Link-Baum.

Geprüft

Beleg geprüft

Eine Angabe ist am Beleg oder am Ergebnis selbst nachgeprüft, zum Beispiel Inhaberschaft, Urkunde, Funktions- oder Wirkungsweise.

Abgenommen

Vom Auftraggeber bestätigt

Der damalige Auftraggeber hat das Ergebnis bestätigt. Der Prüfer hat die Antwort gesichtet. Bestätigt ein Agent, dann im Auftrag seines Betreibers, mit verantwortlicher Person.

Was der Abnehmer sieht

Kein Konto nötig

Ein Klick auf den Link genügt. Jeder Eintrag zeigt Stufe, Prüfweg, Datum und wer bestätigt hat.

Nur, was Sie freigeben

Jeder Abnehmer bekommt seinen eigenen Link mit Ihrer Auswahl. Sie können ihn jederzeit widerrufen.

Offene Punkte sichtbar

Ungeprüftes steht als „Eingereicht“ da, nicht versteckt. Das macht den Rest glaubwürdig.

Häufige Fragen

Wer sieht meine Seite?

Nur, wer einen Ihrer persönlichen Links hat. Ein Link sieht so aus: abgeklopft.de/ihr-name/firma-x7k2…. Ihr Name und die Abnehmerbezeichnung stehen lesbar darin, Ihr Profil bleibt ohne den vollständigen Link unsichtbar. Es gibt keine Seite unter abgeklopft.de/ihr-name allein und keinen Eintrag in Suchmaschinen. Jeder Link hat ein Ablaufdatum und lässt sich widerrufen. Wer einen Link öffnet, erfährt vorher, dass Sie das Öffnen sehen.

Ist das eine „Beglaubigung“?

Nein. „Beglaubigung“ ist in Deutschland ein Rechtsbegriff für Notare und Behörden. Hier gibt es private Attestationen. Sie bestätigen einen Prüfstand, aber keine rechtliche Gleichwertigkeit mit einem Abschluss.

Vermitteln Sie Stellen?

Nein. Sie entscheiden selbst, wem Sie den Link schicken. Wir schlagen keine Kandidaten vor und bringen niemanden zusammen.

Was, wenn ein Auftraggeber aus Gefälligkeit bestätigt?

Die Bestätigung nennt Namen, Rolle und Firma. Sie gilt nur über eine geprüfte Firmenadresse. Wer falsch bestätigt, steht mit seinem Namen dafür ein.

Kann KI die Belege fälschen?

Dokumente ja. Deshalb zählen Inhaberschaft, Abgleich beim Aussteller, Bestätigung durch Dritte und Fachgespräch mehr als ein hochgeladenes PDF.

Können KI-Assistenten die Nachweise lesen?

Ja. Jedes Profil gibt es auch als JSON (dort heißen die Stufen S1 Angabe, S2 Geprüft, S3 Bestätigt; auf der Webseite „Eingereicht“, „Geprüft“, „Abgenommen“), zum Beispiel abgeklopft.de/alex.json oder abgeklopft.de/belegleser.json. Geprüfte Einträge tragen einen signierten Prüfbericht, den ein Assistent selbst nachrechnen kann. Die Anleitung steht in llms.txt. Eigene Angaben der Person sind dabei getrennt gekennzeichnet.

Kann ein KI-Agent ein eigenes Profil haben?

Ja. Den Antrag stellt sein Betreiber, eine Firma oder eine Person. Zuerst wird der Betreiber geprüft. Danach bestätigen frühere Auftraggeber die Arbeit des Agenten, oder er löst eine Probeaufgabe. Das Profil zeigt immer, dass es ein Agent ist, wer ihn betreibt und für welche Version die Prüfungen gelten.

Darf mein Agent einen Bewerber oder Agenten auswählen?

Einen Agenten auswählen und beauftragen darf Ihr Agent selbst, wenn Sie es erlauben. Bei Personen trifft die Entscheidung eine Person (Art. 22 DSGVO). Ihr Agent darf die Nachweise aber lesen, prüfen und zusammenfassen.

Wer erkennt das an?

Heute niemand automatisch. Der Wert entsteht, wenn Abnehmer die Siegel lesen und ihnen trauen. Das prüft der Pilot.
